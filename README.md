# 亮眸训练营 · 间歇性外斜视家庭视功能训练

一个面向 **间歇性外斜视 + 屈光不正** 儿童的家庭视功能训练应用，作为医生院内训练（每周 3 次）的**辅助工具**。训练内容严格对应处方三大方向 **集合 / 融像 / 调节**，并补充 **抗抑制 / 立体视维持 / 放松**。

> ⚠️ 本应用是临床训练的家庭辅助，**不替代**医生院内训练与定期复查；应用内自测数值非临床诊断；出现持续复视/头痛/头晕/恶心/眼痛请立即停止。建议家长陪同使用。非医疗器械，数据仅存本机。

## 运行

```bash
npm install      # 首次安装依赖
npm run dev      # 本地开发，浏览器打开 http://localhost:5173
npm run build    # 构建生产版本到 dist/
npm run preview  # 预览构建产物
```

手机/平板访问：和电脑在同一 WiFi 下，用平板浏览器打开终端里显示的 `Network` 地址（如 `http://10.x.x.x:5173`）。可「添加到主屏幕」当作 App 使用（PWA，支持离线）。

## 功能

- **今日训练**：按每周 3 次排程，一次约 15–25 分钟的引导式会话（热身→集合→融像→调节→放松，解锁后含抗抑制/立体视），完成打卡。
- **免眼镜核心练习**：笔尖推进(集合近点)、Brock 线、集合追踪、自由空间融像(扩展集合范围)、Hart 远近表(调节)、反转拍计时、眼动热身、20-20-20 远眺。
- **红青模块（默认锁定）**：购买红青(红蓝)立体眼镜后在「家长后台」开启，解锁红青可变矢量融像、抗抑制小游戏、随机点立体视。
- **进度与报告**：集合近点 / 融像分离角 / 调节灵敏度趋势图，连续打卡、星星、徽章；一键**导出 PDF 报告**带去 3 个月复查。
- **家长后台（PIN 保护）**：训练日/时长/难度调节、模块开关、提醒、基线编辑、训练记录、屏幕校准、清除数据。
- **屏幕校准**：用银行卡标定每厘米像素，让融像/集合的角度换算更准确。

## 技术栈

React 18 + TypeScript + Vite + Tailwind CSS + Zustand(本地持久化) + Recharts + jsPDF/html2canvas + vite-plugin-pwa。无后端，全部数据保存在浏览器本机。

## 临床设计依据

间歇性外斜视训练核心：消除抑制、扩大融合性集合范围（正融像性聚散）、改善集合近点、训练调节幅度/灵敏度、维持立体视。参考：Journal of Optometry (PMC8258130)、MedCrave AOVS、EyeWiki: Intermittent Exotropia、解放军总医院学报（同视机评估间歇性外斜视）。
